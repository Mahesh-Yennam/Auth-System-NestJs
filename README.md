# NestJS Authentication API

A secure authentication backend built with NestJS, Prisma, and PostgreSQL. The project implements user registration, login, logout, JWT authentication, refresh token rotation, password hashing with bcrypt, request validation, and protected routes using NestJS guards.

## Features

* User Registration
* User Login
* User Logout
* JWT Authentication
* Refresh Token Rotation
* Password Hashing (bcrypt)
* Request Validation (class-validator)
* Protected Routes with Guards
* Prisma ORM
* PostgreSQL Database
* Docker Compose Setup
